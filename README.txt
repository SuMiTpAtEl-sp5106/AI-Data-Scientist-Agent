# 🤖 AI Data Scientist Agent

## 📌 Overview

AI Data Scientist Agent is an automated machine learning application that analyzes user-provided datasets, performs data preprocessing, trains multiple machine learning models, and recommends the best-performing model based on evaluation metrics.

The application aims to simplify the machine learning workflow through automation and AI-powered assistance.

## ✨ Key Features

- Automated dataset analysis
- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Automated machine learning model selection
- Training and evaluation of multiple ML models
- Performance comparison using evaluation metrics
- Recommendation of the best-performing model
- AI-powered assistance using Groq LLM
- Interactive user interface using Streamlit

## 🛠️ Tech Stack

- **Programming Language:** Python
- **Data Processing:** Pandas, NumPy
- **Machine Learning:** Scikit-learn
- **Data Visualization:** Matplotlib, Seaborn
- **LLM Integration:** Groq (ChatGroq)
- **Frontend:** Streamlit

## ⚙️ How It Works

1. Upload a dataset in the application.
2. Analyze the dataset structure, features, and data types.
3. Perform data preprocessing and cleaning.
4. Train suitable machine learning models.
5. Evaluate and compare model performance.
6. Recommend the best-performing model based on evaluation metrics.
7. Use AI-powered assistance to understand the analysis and results.
